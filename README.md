# مشروع تحليل أرباح متجر Superstore

## رابط التطبيق
[افتح لوحة تحليل أرباح Superstore على Streamlit](https://superstore-profit-analysis-4zbpvbj4rxlkcmt6fnnknt.streamlit.app/)


## وصف المشروع
مشروع لتحليل بيانات مبيعات متجر Superstore باستخدام Python، بهدف فهم أسباب انخفاض الأرباح رغم ارتفاع المبيعات، ودراسة تأثير الخصومات وفئات المنتجات والمناطق على الربحية.

## المشكلة
يحقق المتجر مبيعات مرتفعة، لكن بعض العمليات والمنتجات تسجل خسائر. يسعى المشروع إلى اكتشاف مصادر الخسارة وتقديم توصيات مبنية على البيانات.

## أهداف المشروع
- تحليل أرباح المنتجات والفئات المختلفة.
- دراسة العلاقة بين الخصومات والأرباح.
- مقارنة أداء المناطق.
- اكتشاف العمليات ذات الخسائر المرتفعة.
- تطوير لوحة تحكم تفاعلية باستخدام Streamlit في المراحل القادمة.

## البيانات المستخدمة

## نتائج التحليل الأولي
### 1. الأرباح حسب فئات المنتجات
حققت التكنولوجيا أعلى إجمالي أرباح بقيمة 145,454.95 دولار، بينما سجل الأثاث أقل إجمالي أرباح بقيمة 18,451.27 دولار.

### 2. تأثير الخصومات
أظهر التحليل أن الخصومات المرتفعة ارتبطت بمتوسط أرباح سالب في البيانات. فعند خصم 30% بلغ متوسط الخسارة 45.68 دولار، وعند خصم 50% بلغ متوسط الخسارة 310.70 دولار.

### 3. الأرباح حسب المناطق
سجلت المنطقة الغربية أعلى إجمالي أرباح بقيمة 108,418.45 دولار، بينما سجلت المنطقة الوسطى أقل إجمالي أرباح بقيمة 39,706.36 دولار.

## مفاجآت البيانات
- لم تظهر صفوف مكررة أو قيم مفقودة في الفحص الأولي.
- يوجد 1,871 سجلًا بأرباح سالبة.
- بلغت أكبر خسارة في سجل واحد 6,599.98 دولار.
- ارتبطت أكبر خمس خسائر بخصومات بين 50% و80%.

هذه نتائج وصفية ولا تثبت أن الخصومات وحدها سببت الخسائر.

## طريقة تشغيل التحليل
1. تنزيل ملفات المشروع من GitHub.
2. فتح notebook.ipynb باستخدام Google Colab.
3. رفع ملف data/raw.csv إلى بيئة Colab، أو تعديل مسار القراءة ليتوافق مع مكان الملف.
4. تشغيل الخلايا بالترتيب لمراجعة النتائج والرسوم البيانية.
## طريقة تشغيل لوحة Streamlit

بعد تنزيل ملفات المشروع، افتح الطرفية من مجلد المشروع وشغّل:

```bash
pip install -r requirements.txt
streamlit run app.py
```

تقرأ اللوحة البيانات من [ملف البيانات المنظّف](data/clean.csv).
